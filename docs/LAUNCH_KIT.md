## Show HN

**Title:** Show HN: MaglaSync – local continuity between ChatGPT, Claude, and Gemini

**Text:**

> I built MaglaSync because long-running AI projects keep losing context when a chat becomes too long or I switch models.
>
> It is a free Manifest V3 browser extension that keeps one project journal locally. It captures visible messages on ChatGPT, Claude, and Gemini, extracts structured decisions and next steps, and fills an empty new chat with the current context. It never presses Send.
>
> There is no account, API key, analytics, backend, or remote runtime code. The source, privacy disclosure, tests, and installable ZIP are public. The current GitHub edition uses Chrome's Load unpacked flow while the store listing is prepared.
>
> I would especially value feedback on the context format, privacy boundary, and compatibility with real long-running projects.

>
> The Free edition deliberately avoids a backend. One project stays in browser extension storage, messages are captured on supported sites, and a structured continuity block carries decisions, verified results, blockers, and next steps forward. The user always reviews the prepared context and presses Send.
