# MaglaSync Social & News Distribution V1

Goal: grow Chrome and Firefox installs organically with zero paid spend.

## Ground rules

- No paid placement, paid reviews, fake accounts, incentives, or bulk unsolicited spam.
- Use the platform's own submission or self-promotion rules.
- One factual submission per channel unless the platform explicitly allows updates.
- Keep Chrome and Firefox links separate so traffic and conversion can be reconciled independently.
- Treat submitted as pending until publication or acceptance is directly evidenced.

## Core angles

1. Cross-AI continuity: keep project context when moving between ChatGPT, Claude and Gemini.
2. Local-first privacy: no MaglaSync account, analytics backend, or AI API key required.
3. Project memory instead of transcript dumping: user reviews the context before carrying it forward.
4. Open source and available on both Chrome and Firefox.

## Channel-specific launch shapes

### Reddit / community threads

Use only explicit self-promotion threads or communities whose rules permit project sharing.

Structure: problem first, disclose that the author built it, explain what it does, list privacy boundary, ask for specific feedback, then one install/source link set. No fake testimonials or vote manipulation.

Current verified target: r/ChatGPTCoding weekly self-promotion thread. Do not repeat weekly unless there is a meaningful product update.

### Hacker News / Show HN

Title pattern: `Show HN: MaglaSync – local project continuity across ChatGPT, Claude and Gemini`

Body: short technical explanation, why it exists, local-only design, browser support, source link. Avoid marketing claims and calls for upvotes.

### Product Hunt

Position as a free open-source browser extension. Lead with the user pain and show a short demo. Use Chrome Extensions / Productivity / AI tags where available. No paid boosting.

### Telegram / AI news channels

Pitch as a news item, not an ad: free open-source release, what problem it solves, Chrome + Firefox availability, local-first boundary. Use a channel's official 'suggest news' or editorial contact only.

### Newsletters / AI tool curators

Use official recommend-a-tool or editorial intake. Keep the submission to name, URL, category, one-sentence benefit, and factual differentiators. Do not buy newsletter placement.

### Newsrooms / tech media

Use public tips/pitch routes only. Frame the story around the broader cross-AI interoperability/continuity trend; offer MaglaSync as a verifiable open-source example, not as a demand for coverage.

### X / LinkedIn / Threads

When an authorized posting channel becomes available, publish short maker updates around releases, comparisons, privacy boundary, and concrete workflows. Avoid posting the same text verbatim across networks.

### YouTube / short video

Create 20–45 second demonstrations: 'move a project from ChatGPT to Claude', 'resume in Gemini', and 'what stays local'. The CTA is the official Chrome/Firefox listing. No fabricated user counts.
