# MaglaSync First 200 Real Users

Goal: recruit and learn from the first 200 real multi-AI users without paid acquisition, fake accounts, incentivized reviews, or bulk unsolicited outreach.

This lane is deliberately separate from directories, journalists, SEO impressions, GitHub stars, and browser-store page views. Those channels may feed the lane, but they do not count as a real-user contact by themselves.

## What counts toward 200

A row counts as `counts_as_user_contact=yes` only when all of these are true:

1. The person or team demonstrably uses or teaches a workflow involving at least two of ChatGPT, Claude, Gemini, or equivalent AI assistants.
2. There is a public, legitimate contact route or an existing relationship/channel where a personal message is appropriate.
3. The message asks them to install/test MaglaSync in their own workflow and give an honest verdict.
4. The outreach is individual and contextual, not a template blast.

A directory submission, press pitch, generic newsletter inbox, scraped address, guessed address, paid listing, or community post does not count as a First-200 contact unless a named practitioner actually enters a test conversation.

## Funnel

`qualified practitioner → individual test ask → reply → test confirmed → install confirmed → useful session → feedback → optional honest review/share`

The important denominator is not emails sent. Track every step separately in `growth/first_200_ledger.csv`.

## Core ICP

Priority A:

- People who actively switch between ChatGPT, Claude, and Gemini for one project.
- Developers/founders with long-running AI-assisted work that regularly overflows one chat.
- Writers/researchers/consultants who compare models and manually carry briefs, decisions, drafts, or client context between them.
- AI educators who publish real multi-model workflows and can personally test the product.

Priority B:

- Teams using two AI providers but not yet reporting a continuity problem.
- Browser-extension makers or AI workflow product builders who are themselves multi-model power users.

Do not pursue people whose only relationship to AI is generic news coverage.

## Individual message rule

Each message must contain the concrete evidence that qualified the person. The default structure is:

- one sentence showing the exact workflow/problem they publicly described;
- one sentence explaining the narrow MaglaSync fit;
- direct request to test it in that same workflow;
- reviewer/install/source links;
- explicit request for criticism, not a positive review;
- no payment, affiliate, sponsorship, or reward.

## Feedback questions after a confirmed test

Keep follow-up short:

1. Did setup make sense without help?
2. At what moment did the handoff save time — or fail to?
3. Was the generated project state too long, too short, or wrong?
4. Would you use it again in a real project next week?
5. What one change would make the answer to #4 become yes?

Never ask for a five-star rating. After demonstrated useful use, the extension may expose its existing voluntary **Leave an honest review** action.

## Operating batches

Work in small batches so feedback can change the product before the next batch:

- Batch 1: contacts 1–10 — multi-AI educators/practitioners and peer builders with public workflows.
- Batch 2: 11–30 — developers/founders and long-running-project users.
- Batch 3: 31–75 — specialists/writers/researchers who use 2+ models.
- Batch 4: 76–200 — only after activation/retention evidence shows the product is worth widening.

A batch is not advanced merely because messages were sent. Review replies, confirmed tests, activation friction, and repeated-use intent first.

## Success gates

First signal: **PASS — 10 qualified contacts sent with no duplicate/spam behavior.**

Learning gate: at least 3 people confirm an actual test and at least 2 return actionable feedback.

Activation gate: at least 5 independent users can create a project, connect a chat, and perform a fresh-chat handoff without owner assistance.

Repeat-use gate: at least 3 independent users say they would use MaglaSync again on a real project or demonstrate a second use.

Only after those gates should the system optimize for volume toward 200. The purpose of the first 200 is to create a product people keep installed, not to manufacture an install counter.
