Use these as normal topical community posts. Do not pretend to be an unrelated user, invent testimonials, user counts or reviews. Before each send, the live target check decides whether links/self-promotion are currently allowed.

## V1 — problem first / general AI

Кто ведёт длинные проекты через ChatGPT, Claude или Gemini — сделали бесплатное расширение, чтобы не пересказывать контекст при каждом новом чате.

**MaglaSync Free** хранит состояние проекта локально в браузере: цель, правила, принятые решения, факты, препятствия и следующие шаги. Перед переносом в новый чат показывает подготовленный контекст — его можно проверить и изменить, а Send всегда нажимает сам пользователь.

Без аккаунта, API-ключа и нашего облачного сервера. Open source.

https://sync.magla.ru/

Исходники: https://github.com/340867-ux/MaglaSync

## V2 — cross-AI workflow

Небольшой инструмент для тех, кто в одном проекте прыгает между **ChatGPT → Claude → Gemini**.

**MaglaSync Free** держит локальный журнал проекта и собирает актуальный контекст для нового чата, чтобы не тащить вручную старую переписку и не объяснять всё заново.

Подключаются только выбранные пользователем чаты. Ничего автоматически не отправляется: сначала видите контекст, затем сами решаете, что вставить и отправить.

Бесплатно и open source: https://sync.magla.ru/

## V3 — developer / open source

Сделали open-source browser extension для одной раздражающей задачи: продолжать проект в новом AI-чате без ручного пересказа истории.

**MaglaSync Free** работает с ChatGPT, Claude и Gemini, хранит проект локально и формирует компактное состояние проекта перед продолжением работы в новом чате.

Нет обязательной регистрации, собственного AI API и облачного backend для хранения проекта. Код открыт:
https://github.com/340867-ux/MaglaSync

Установка: https://sync.magla.ru/

## V4 — privacy first

Если не хочется отдавать ещё одному сервису историю AI-проектов: **MaglaSync Free** хранит состояние проекта локально в браузере.

Вы сами подключаете нужные разговоры, сами проверяете подготовленный контекст и сами нажимаете Send. Расширение нужно только для того, чтобы новый ChatGPT, Claude или Gemini быстро получил актуальное состояние работы.

Без аккаунта и внешнего сервера хранения проекта.

https://sync.magla.ru/

Open source: https://github.com/340867-ux/MaglaSync

## V5 — automation / n8n / Make communities

Для тех, кто строит рабочие процессы вокруг AI и постоянно меняет модели: сделали **MaglaSync Free**.

Он не автоматизирует саму отправку сообщений. Его задача другая — локально держать состояние проекта и готовить актуальный контекст, когда работа переезжает из одного ChatGPT/Claude/Gemini-чата в другой.

Получается меньше ручного copy-paste и повторных объяснений, при этом финальный текст всегда контролирует пользователь.

https://sync.magla.ru/
