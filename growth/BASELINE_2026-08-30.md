# MaglaSync organic growth baseline — 2026-08-30

This document freezes the first evidence-grade baseline for the zero-budget 50K-per-store acquisition program.

It is deliberately conservative. A source release, an outreach email, or a submission request is **not** counted as a public store update, a directory placement, a media mention, or an install until evidence for that state exists.

## Primary goal

- Chrome Web Store: 50,000 installs/users.
- Mozilla Add-ons: 50,000 installs/users.
- Paid acquisition budget: **0**.
- Forbidden shortcuts: purchased installs, fake accounts, review farms, incentivized ratings, paid review exchanges, unsolicited bulk spam, or claims unsupported by store/public evidence.

## Store update pipeline

A guarded manual GitHub Actions workflow now exists for future store submission:

`.github/workflows/store-submit.yml`

It requires an explicit `SUBMIT` confirmation and never runs on push.

One-time publisher secrets still required before the workflow can actually submit store updates:

### Chrome

- `CWS_CLIENT_ID`
- `CWS_CLIENT_SECRET`
- `CWS_REFRESH_TOKEN`
- `CWS_PUBLISHER_ID`

### Firefox

- `AMO_JWT_ISSUER`
- `AMO_JWT_SECRET`

Until these exist and a submission is actually run, v1.2.3 remains a GitHub/source release rather than a claimed store-public update.

## Measurement rules from this baseline forward

Track Chrome and Firefox separately.

For each store record:

- public version;
- public users/install indicator when available;
- rating count and average;
- review count;
- listing availability;
- meaningful review or policy changes.

For acquisition record:

- new independent web mentions/backlinks;
- directory acceptance/rejection;
- editorial replies/coverage;
- GitHub stars/forks/issues when they indicate real adoption;
- which organic landing pages become indexed or earn links;
- outbound submission count separately from accepted placement count.

A daily condition-watch is active for meaningful store, mention, backlink, review, and Gmail-reply changes. Silence means no meaningful change was detected; it is not proof that every external source was exhaustively refreshed.
