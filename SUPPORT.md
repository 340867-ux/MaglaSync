# MaglaSync support

Use [GitHub Issues](https://github.com/340867-ux/MaglaSync/issues) for compatibility reports, defects, and feature requests.

## Before reporting a problem

1. Confirm that MaglaSync Free is enabled at `chrome://extensions` or `edge://extensions`.
2. Reload the affected ChatGPT, Claude, or Gemini tab.
3. Confirm that the exact conversation shows **Connected** in the MaglaSync panel.
4. Confirm that **Save connected chats** is enabled in the project journal.
5. For context placement, make sure the message box is empty and choose **Review context**.

## Protect private conversations

Never paste a private chat, exported backup, cookie, access token, account identifier, or personal project data into a public issue. A useful report needs only:

- AI site and visible page type;
- browser and MaglaSync version;
- exact steps that reproduce the behaviour;
- expected and observed result;
- a cropped screenshot with private content removed, if necessary.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
