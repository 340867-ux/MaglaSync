ГДЕ РАБОТАЕТ

Один продукт, правильный установщик для каждого браузера.

Расширения безопаснее устанавливать из магазинов браузеров: одна кнопка, проверка площадки и автоматические обновления.

Пакет готов

Windows, macOS, Linux

Chrome, Microsoft Edge, Brave и Opera используют Chromium‑пакет. GitHub‑версия доступна сейчас; публикации в Chrome Web Store и Edge Add‑ons требуют аккаунтов владельца и проверки.

Кандидат на проверку

Firefox и Android

Подготовлен отдельный Firefox‑пакет с мобильным event page. Перед выдачей пользователям Mozilla должна подписать его, а критический путь надо проверить на реальном Android.

App Store

Mac, iPhone, iPad

Подготовлен Safari WebExtension source. Установочная версия появится после подписи Apple, теста на устройствах и проверки App Store.

Почему нет отдельного EXE: для Chrome и Edge кнопка магазина и есть нормальный установщик. Отдельный EXE не даст доверенной установки и автообновлений. Chrome на Android не поддерживает расширения; мобильный путь — Firefox Android, а на iPhone и iPad — Safari после App Store.
