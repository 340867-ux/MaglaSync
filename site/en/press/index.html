MaglaSync in 30 seconds.

MaglaSync Free is an open-source browser extension that carries the current state of a project between ChatGPT, Claude, and Gemini. It is deliberately different from full-chat migration tools: the object being carried is the project — goal, decisions, constraints, blockers, recent evidence, and next steps.

Price

Free. The public Free edition needs no MaglaSync account or AI API key.

License

MIT. Source, privacy disclosure, release history, tests, and packaging are public.

Supported AI chats

ChatGPT, Claude, and Gemini web apps. Chats are disconnected by default.

Storage model

The Free project journal stays in browser extension storage; MaglaSync has no journal backend.

Human control

The handoff is shown for review/editing. MaglaSync does not press Send for the user.

Current source release

v1.2.4. Browser-store review and rollout can lag the source release.

Fast reviewer test

  1. Install from the signed Chrome or Firefox listing.
  2. Create one local project with a name and goal.
  3. Open ChatGPT, Claude, or Gemini and explicitly connect that conversation.
  4. Work normally and save a few project updates.
  5. Open a fresh supported chat, review the generated handoff, edit it if useful, and place it into the new composer.
  6. Confirm the extension leaves the final Send action to you.

What is different

Project state, not a transcript ferry. Full transcripts are useful for one-off migration. MaglaSync instead keeps a compact working state designed for projects that continue over many chats.
Consent-first capture. Opening an AI site does not connect the chat. Each conversation starts disconnected and is only included after an explicit user action.
Local-first boundary. The Free edition does not require a MaglaSync cloud, analytics SDK, remote runtime code, or an AI API client.
Cross-browser availability. The same project-memory concept is published for both Chrome/Chromium and Firefox.
International store identity. Source release 1.2.4 includes localized extension name and description metadata for 13 high-reach locales without changing permissions or data handling.

Useful editorial angles

  • Full-chat transfer vs. portable project memory: which object is actually useful after a conversation grows?
  • Cross-AI continuity without creating another cloud account.
  • What explicit per-chat consent changes for extensions that can read AI conversations.
  • Why browser-local state can be a practical interoperability layer between competing AI providers.

Privacy and verification

The source package has release checks that reject unexpected Chromium permissions, remote scripts, network runtime primitives, eval, and Function constructors. Integrity checks detect changes in saved journal history; they are not a claim that AI-generated statements are true.
