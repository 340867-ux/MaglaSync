GUIDE · AI CONTEXT HANDOFF

Move the project state — not the entire chat transcript.

When you move from ChatGPT to Claude, from Claude to Gemini, or simply open a fresh AI conversation, the most useful thing to carry is a compact snapshot of the project as it exists now.

The seven-part handoff checklist

  1. Goal: What outcome is the project trying to reach?
  2. Current state: What has actually been completed or established?
  3. Constraints: What rules, limits, formats, technologies, deadlines, or boundaries must remain true?
  4. Decisions: Which choices have already been made, and which alternatives were deliberately rejected?
  5. Evidence: Which results are verified facts, and which are only claims made earlier in the conversation?
  6. Blockers: What is currently preventing progress or still uncertain?
  7. Next step: What should the new chat do first?

A copyable manual template

PROJECT GOAL: [one clear outcome] CURRENT STATE: [what is already done] CONSTRAINTS: - [constraint 1] - [constraint 2] DECISIONS ALREADY MADE: - [decision + short reason] VERIFIED EVIDENCE: - [fact that was independently checked] UNVERIFIED / NEEDS RECHECKING: - [claim inherited from an earlier AI response] BLOCKERS / OPEN QUESTIONS: - [blocker] NEXT STEP: [first concrete action for this chat]

Why not paste the whole transcript?

Full transcripts contain abandoned ideas, duplicated instructions, stale assumptions, conversational filler, and statements that may never have been verified. Copying all of that into a new model makes the new conversation inherit noise as well as useful context.

A handoff is deliberately smaller. It should preserve the state that still matters while making uncertainty visible.

Review before you send

Do not treat a generated handoff as automatically correct. Read it once. Remove private details the next provider does not need. Delete stale instructions. Mark old AI claims as unverified when they were never independently checked.

Useful rule: project memory is a record of what the project currently believes or has observed — not proof that every remembered statement is true.

When to make a handoff

Create one before a conversation becomes unwieldy, before switching AI providers, after a major project decision, after an important test result, or whenever a fresh chat would otherwise require a long explanation from scratch.
