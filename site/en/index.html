THE IMPORTANT QUESTIONS

Before you install

Does MaglaSync write or send messages by itself?

No. It only prepares context in an empty message box. You see the text and press Send yourself.

Do I need an account or API key?

No. MaglaSync Free requires neither a MaglaSync registration nor an AI service API key.

Where is my project stored?

Inside the installed extension's local storage. You can download a backup or delete all data.

Which chats work in the first version?

The web versions of ChatGPT, Claude, and Gemini in Chrome or Microsoft Edge on desktop. Other browsers and mobile versions come after the main version is proven with real users.
