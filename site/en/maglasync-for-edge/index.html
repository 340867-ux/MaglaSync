Use MaglaSync in Microsoft Edge from the same signed Chrome Web Store listing.

Microsoft documents that extensions designed for Google Chrome can also be used in Microsoft Edge. MaglaSync's Chromium edition is distributed through the Chrome Web Store, so Edge users can install the same signed package instead of sideloading a ZIP.

Install MaglaSync in Edge

How to install it in Edge

  1. Open the MaglaSync Chrome Web Store listing in Microsoft Edge.
  2. If Edge asks whether to allow extensions from other stores, choose Allow.
  3. Review the extension permissions and choose to add the extension.
  4. Open MaglaSync, create the local project, then explicitly connect only the AI chats that belong to it.
Why this still fits MaglaSync's privacy model

Using Edge does not create a MaglaSync cloud account. The Free project journal remains in the installed extension's local browser storage, the handoff stays visible for review, and MaglaSync never presses Send for you.

What MaglaSync does in Edge

  • Keeps one project's current state across ChatGPT, Claude, and Gemini chats you explicitly connect.
  • Carries goals, decisions, constraints, reported results, blockers, next steps, and bounded recent context.
  • Lets you start a fresh AI chat without manually rebuilding the project first.
  • Adds no MaglaSync analytics backend or AI API requirement.

Why the Chrome Web Store link is the normal route

Microsoft's own Edge support documentation says Chrome extensions can be installed from the Chrome Web Store. For ordinary users, MaglaSync therefore links to the signed store item rather than asking Edge users to enable developer mode or install an unpacked build.
