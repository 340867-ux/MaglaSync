# MaglaSync Free 1.1.0

**Local-first Free, prepared for every major browser family.**

## Included

- Production Chromium package for Chrome, Microsoft Edge, Brave, and Opera on desktop.
- Firefox event-page package prepared for desktop and Android testing/signing.
- Safari WebExtension source package prepared for macOS, iPhone, and iPad App Store conversion.
- Cross-browser runtime adapter using the standard `browser` or `chrome` extension namespace.
- Russian/CIS product page at `sync.magla.ru`, with an English version at `/en/`.
- Store, Telegram, YouTube, and TikTok launch materials.
- Local-first Free / optional encrypted Pro architecture and an honest platform release matrix.

## Install now

Chrome and Edge users can download `maglasync-free-chromium-v1.1.0.zip`, extract it, and use **Load unpacked** until the store listings are approved.

The Firefox archive is unsigned. Mozilla must sign it before ordinary Firefox and Firefox Android users can keep it installed. The Safari archive is source for Apple packaging, not a signed app; App Store installation requires the publisher's Apple account, signing, device testing, and review.

## Privacy

The Free runtime still has no MaglaSync account, backend, telemetry, advertising, or remote code. Project data remains in browser extension storage. MaglaSync prepares context but never presses Send.
