# MaglaSync Context Bridge for Moodle

A local Moodle plugin for teachers and managers. It prepares a reviewable context packet from the current course: course name, short name, summary and visible activities. The teacher can copy that packet into ChatGPT, Claude, Gemini or another AI assistant.

## Privacy boundary

- No MaglaSync account.
- No analytics or advertising.
- No AI API key.
- No MaglaSync backend.
- Nothing is sent automatically.
- The plugin stores no personal data of its own.

## Install

Copy `maglasync_context` to `local/maglasync_context`, visit Site administration to complete installation, then open a course as a manager or editing teacher and choose **AI Context**.

Version: 0.1.0
