Build a local, reviewable AI context handoff from the current WordPress post or page.

== Description ==

MaglaSync Context Bridge adds a small editor-side panel that prepares structured context from the current post or page. The editor can review the text and copy it into ChatGPT, Claude, Gemini, or another AI assistant.

Privacy boundary:
* No MaglaSync account.
* No analytics or advertising.
* No AI API key.
* No remote MaglaSync backend.
* Nothing is sent automatically.

== Installation ==

1. Upload the `maglasync-context` folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Edit a post or page and open the MaglaSync AI Context panel.
4. Review and copy the generated context.
